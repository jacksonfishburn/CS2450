# User Stories

- As a Student, I want to be able to upload a variety of files, so that I can test and learn about machine language.
- As a Professor, I want to see the output, so that I can make sure the starting file and the additional values entered through the terminal are correct.
- As a math student, I want to create BasicML programs that perform calculations and automate formulas, so that I can quickly calculate results without performing the calculations manually.

# Use Cases

1. User uploads a file to the program. The program runs the file based on the instructions and provides and output.
2. One of these files may ask for the user to input number, the program then takes this number and does the appropriate operation.
3. User can enter positive or negative numbers when the program asks for an input.
4. A program can add two or more numbers together.
5. A program can subtract numbers from each other.
6. A program can multiply numbers together.
7. A program can divide numbers.
8. A program can save a number in a specific memory location.
9. A program can load a number from memory to use in a calculation.
10. A program can display a number or result to the user.
11. A program can repeat certain instructions using a branch instruction.
12. A program can check if a number is negative or zero and branch to another part of the program.
13. A program stops when it reaches the HALT instruction.
14. A program gives an error if it tries to do something invalid, such as divide by zero.
