## 15 Functional Requirements

1. The program shall include a input box for the read operation.
2. The program shall display the instruction contents.
3. The program shall allow a user to step through instructions.
4. The program shall include a way to load in a file.
5. The program shall display errors through the GUI.
6. The program shall allow a user to run a loaded program.
7. The program shall display the current accumulator value.
8. The program shall display the current instruction being executed.
9. The program shall display the contents of memory.
10. The program shall allow a user to clear the current program.
11. The program shall allow a user to restart program execution.
12. The program shall display program output through the GUI.
13. The program shall allow the user to enter data when a READ instruction is executed.
14. The program shall stop program execution when a HALT instruction is executed.
15. The program shall prevent execution of a program when the loaded file contains an invalid instruction.

## 3 Non-functional Requirements

1. The program shall provide clear labels for all user interface controls.
2. The program shall respond to user actions within a reasonable amount of time.
3. The program shall use consistent formatting for displaying instructions, memory values, and program output.
