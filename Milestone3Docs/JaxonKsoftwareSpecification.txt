15 Functional: 

The system shall allow a file to be uploaded. 

The system shall process the uploaded file and notify the user if the file is incompatible. 

The system shall be able to place a number in the accumulator when instructed. 

The system shall store the number in the accumulator until it needs to be processed or changed. 

The system shall add the number in the accumulator and another number together when instructed. 

The System shall subtract a given number from the number in the accumulator when instructed. 

The system shall multiply a number in the accumulator with another given number when instructed. 

The system shall divide the number in the accumulator by another number when instructed. 

The system shall take user input during execution when instructed. 

The system shall truncate any value greater than 9999. 

The system shall output a result when instructed. 

The system shall branch to different memory locations when instructed. 

The system shall process through each command until the exit code is provided. 

The system shall stop execution gracefully if no stop command is provided 

The system shall catch any invalid commands and notify the user without crashing.

The system shall have an easy-to-use GUI.
